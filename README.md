# 🚀 Калькулятор окупаемости B2B-аутрича Call-Talk

Интерактивный веб-калькулятор юнит-экономики и окупаемости лидогенерации для сейлз-команды Call-Talk и презентации клиентам.

---

## 💎 Возможности калькулятора

1. **Тарифные планы Call-Talk:**
   - **4 месяца (Флагман):** фикс `39 000 руб./мес` (единоразово `156 000 руб.`), база `5 100 контактов`, прогноз `63–94 лида` (в среднем `78`).
   - **2 месяца (Тест):** фикс `56 000 руб./мес` (единоразово `112 000 руб.`), база `2 100 контактов`, прогноз `27–41 лид` (в среднем `34`).

2. **Форматы оплаты за результат:**
   - **MQL (Подтвержденный интерес):** базовая ставка (`1 800` / `2 800` / `4 800 руб.`).
   - **SQL (Подтвержденная встреча / созвон под ТЗ):** ровно **в 3 раза выше (x3)** (`5 400` / `8 400` / `14 400 руб.`), с автоматической адаптацией конверсии под разогретого ЛПР (до 25–40%).

3. **Сетка сложности ниши (по профилю покупателей клиента):**
   - **Уровень 1:** Малый бизнес / ИП (выручка до 500 млн руб., чек до 500 000 руб.) $\rightarrow$ MQL `1 800 руб.` | SQL `5 400 руб.`
   - **Уровень 2 (Дефолт):** Средний бизнес (выручка 500 млн – 1,5 млрд руб., чек 0,5–3 млн руб.) $\rightarrow$ MQL `2 800 руб.` | SQL `8 400 руб.`
   - **Уровень 3:** Крупный бизнес / Enterprise / Холдинги (выручка от 1,5 млрд руб., чек от 3 млн руб.) $\rightarrow$ MQL `4 800 руб.` | SQL `14 400 руб.`

4. **Экономика клиента и стресс-тесты:**
   - Средний чек сделки, чистая маржа (%), конверсия в сделку (%).
   - Учет повторных сделок и LTV.
   - Сценарии: Стресс-тест (консервативный), Реалистичный (базовый), Оптимистичный.

5. **Железобетонная математика окупаемости:**
   - **Точка безубыточности:** наглядно рассчитывает, сколько сделок достаточно закрыть клиенту для полной окупаемости договора (например: *«Достаточно всего 1–2 сделок из 78 лидов!»*).
   - Расчет ROI (%), чистой прибыли, привлеченной выручки, доли затрат на маркетинг в выручке (%) и стоимости привлечения клиента (CAC).

6. **Быстрые пресеты популярных ниш (в 1 клик):**
   - Металлоконструкции (2,5 млн руб.)
   - IT-разработка и SaaS (1,8 млн руб.)
   - Опт и упаковка с LTV (450 000 руб.)
   - Спецтехника и станки (6,5 млн руб.)
   - B2B-консалтинг (900 000 руб.)

7. **Инструменты сейлза:**
   - 📋 Кнопка **«Скопировать клиенту»** — мгновенно формирует готовый выверенный текст для Telegram / WhatsApp / Email с соблюдением всех стандартов Call-Talk.
   - 🔗 Кнопка **«Ссылка»** — копирует персональный URL, в котором сохранены все выбранные параметры (можно отправлять клиенту его персональный расчет).
   - 🖨️ Кнопка **«PDF»** — чистый печатный бланк без кнопок и ползунков.

## 🌐 Как опубликовать на Vercel за 2 минуты

Проект полностью оптимизирован для статического деплоя на Vercel (файлы `vercel.json`, `index.html`, `styles.css`, `app.js`).

### Вариант 1. Через Vercel CLI (самый быстрый)

1. Откройте терминал на вашем Mac и перейдите в папку калькулятора:
   ```bash
   cd "/Users/ulyana/CALL TALK/calculator"
   ```
2. Запустите команду Vercel:
   ```bash
   npx vercel
   ```
3. Следуйте 3 подсказкам в консоли:
   - *Set up and deploy?* $\rightarrow$ **Y**
   - *Which scope?* $\rightarrow$ выберите ваш аккаунт Vercel
   - *Link to existing project?* $\rightarrow$ **N**
   - *Project name?* $\rightarrow$ например: `calltalk-calc`
   - *In which directory is your code located?* $\rightarrow$ `./`
4. Через 10 секунд вы получите готовую живую ссылку вида:  
   👉 `https://calltalk-calc.vercel.app`

Для деплоя в Production (на постоянный домен):
```bash
npx vercel --prod
```

---

### Вариант 2. Через GitHub + Vercel Dashboard

1. Создайте репозиторий на GitHub (например, `calltalk-roi-calculator`).
2. Загрузите файлы из папки `calculator` в репозиторий:
   ```bash
   cd "/Users/ulyana/CALL TALK/calculator"
   git init
   git add .
   git commit -m "Call-Talk ROI Calculator"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/calltalk-roi-calculator.git
   git push -u origin main
   ```
3. Зайдите на [vercel.com](https://vercel.com) $\rightarrow$ нажмите **Add New...** $\rightarrow$ **Project**.
4. Выберите репозиторий `calltalk-roi-calculator` и нажмите **Deploy**.
5. Проект автоматически развернется и будет обновляться при каждом коммите!

## 💻 Локальный запуск на компьютере (без интернета)

Вы можете открыть калькулятор прямо сейчас без установки каких-либо программ:
- Просто дважды кликните по файлу `index.html` в Finder (откроется в Chrome / Safari).
- Либо запустите локальный сервер:
  ```bash
  cd "/Users/ulyana/CALL TALK/calculator"
  python3 -m http.server 3000
  ```
  И откройте в браузере: `http://localhost:3000`
